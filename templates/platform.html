Overview & Platform Vision

Heros is a production-grade AI assistant platform designed to help users chat, analyze complex files, search the web in real-time, manage voice interactions, and work with AI-powered workflows in a secure, reliable environment.

Built on Django and PostgreSQL, Heros combines multiple state-of-the-art AI providers—including Gemini, OpenRouter, and Groq—using an intelligent routing engine named Baymax. This architecture ensures high availability, automatic fallback, low latency, and continuous uptime even if an upstream provider experiences rate limits or service degradation.

What Heros Does

Smart AI Chat

Multi-model routing with intelligent intent recognition to choose the optimal LLM for every query.

Document Analysis

Extract, analyze, and question PDF, DOCX, TXT, images, and structured datasets effortlessly.

Web Research

Real-time search and web synthesis to provide grounded, up-to-date answers for news and research.

Voice & Audio

Integrated Text-to-Speech (TTS) and Whisper speech transcription for hands-free voice interactions.

Secure Keys & OAuth

Fernet symmetric encryption for stored provider keys and seamless Google OAuth sign-in support.

Infinsight RAG

Dataset-aware RAG workflows for deep data retrieval and automated insight generation.

Core System Components

Baymax — Intelligent Router

Baymax is the central routing engine of Heros. It evaluates user prompts, identifies task intent (general chat, coding, file analysis, web search, voice), and routes requests to the best available provider (Gemini, OpenRouter, Groq) with zero manual configuration.

Halo — Task Orchestrator

Halo handles complex, multi-step tasks requiring coordinated AI execution, recursive tool calls, and background workflow execution.

Zeno — Browser Extension

Zeno brings Heros directly into your web browser, allowing text summarization, webpage Q&A, and quick AI prompts without leaving your current page.

Zuno — Voice & Music Experience

Zuno powers voice-driven music requests, audio playback, and hands-free assistant operations.

Infinsight — Dataset RAG Engine

Infinsight enables vector search and retrieval-augmented generation for uploaded CSVs, spreadsheets, and enterprise knowledge bases.

How Heros Works (Execution Pipeline)

1
Request Ingestion:

User sends a text query, audio recording, or document upload via Playground, API, or Zeno extension.

2
NLP Intent & Router Classification:

Baymax analyzes prompt complexity, file type, and web grounding requirements.

3
Multi-Provider Dispatch:

Request dispatched to Gemini, OpenRouter, or Groq. If provider fails, fallback routing executes automatically.

4
Response Processing & Isolation:

Response formatted, streamed, and stored securely according to user session settings.

POST /api/tts — Speech Synthesis with Web Search Grounding 
import requests

# Generates spoken audio stream directly from text with search grounding context
payload = {
    "text": "Here are the latest stock market updates retrieved from the web today.",
    "voice": "alloy",
    "speed": 1.0,
    "enable_web_search": True
}
headers = {
    "Authorization": "Bearer sk-hero-YOUR_API_KEY",
    "Content-Type": "application/json"
}

res = requests.post("https://hero-s-ai.alwaysdata.net/api/tts", json=payload, headers=headers)
with open("response.mp3", "wb") as f:
    f.write(res.content)
print("Saved synthesized audio response to response.mp3")
// Playback audio response directly in the browser
const res = await fetch("https://hero-s-ai.alwaysdata.net/api/tts", {
  method: "POST",
  headers: {
    "Authorization": "Bearer sk-hero-YOUR_API_KEY",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    text: "Here are the latest stock market updates retrieved from the web today.",
    voice: "alloy",
    speed: 1.0,
    enable_web_search: true
  })
});

const audioBlob = await res.blob();
const audioUrl = URL.createObjectURL(audioBlob);
new Audio(audioUrl).play();
curl -X POST "https://hero-s-ai.alwaysdata.net/api/tts" \
  -H "Authorization: Bearer sk-hero-YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Here are the latest stock market updates retrieved from the web today.",
    "voice": "alloy",
    "speed": 1.0,
    "enable_web_search": true
  }' \
  --output response.mp3

Security Architecture & Privacy Policy

Overview of Heros security controls, cryptographic key encryption, and privacy compliance guidelines.

Encryption at Rest (Fernet)

Third-party API provider keys (Gemini, OpenRouter, Groq) are encrypted at rest using AES-128 Fernet symmetric encryption before storing in PostgreSQL.

SHA-256 API Key Hashing

Developer secret keys (sk-hero-...) are shown only once upon generation and saved exclusively as SHA-256 hashes in our database.

TLS 1.3 Transport Security

All API traffic, chat completions, speech transcriptions, and dashboard data travel over HTTPS secured by TLS 1.3 encryption.

OAuth 2.0 & PKCE

Google OAuth single sign-on authentication utilizes state-token verification to prevent cross-site forgery.
